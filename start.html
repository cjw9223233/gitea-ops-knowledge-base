三個位置、兩種執行身分

名稱 位置 用途
正式主機 coffee@10.253.114.160 運行 Docker、Gitea 與 PostgreSQL
備機 coffee@192.168.1.3 接收備份封存檔，尚非已驗收的即時接手服務
本機工作站 Windows 專案資料夾 編輯知識庫與保留報告，不執行 Linux 主機命令

sudo crontab -l 查的是 root 排程。root 負責冷備份與服務控制；新版僅讓 SSH 以 coffee 身分執行，沿用其既有金鑰。遠端登入帳號也叫 coffee，不能只看提示字元判斷目前在哪台機器。

第一次接手的順序

  1. 閱讀 系統與網路，確認服務入口。
  2. 使用 日常巡檢 的唯讀指令確認服務。
  3. 使用 Log 與產出物 查實際備份，分清本機成功與異機成功。
  4. 閱讀 排程管理 與 備份還原，再安排維護。

操作分級

等級 範例 原則
唯讀檢查 ls、tail、crontab -l、healthz 可以先蒐集證據，輸出不要包含密碼或私鑰
變更 安裝更新器、修改設定、授權公鑰 先確認版本、回復方式與管理員權限
中斷服務 執行 daily、重開機、還原資料 僅於核准的維護時段與正確目標執行

不要把聊天中的多行指令直接黏成沒有分隔符號的一行。每次複製一個程式碼區塊；若指令以 && 相連，前一步失敗就會停止。
